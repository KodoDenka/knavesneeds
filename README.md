# Knaves' Needs Multiloader Project

This project uses the [Multiloader Template](https://github.com/jaredlll08/MultiLoader-Template) created by the [Mycelium Mod Network](https://discord.myceliummod.network). Many thanks to their members [Darkhax](https://github.com/Darkhax) and [jaredlll08](https://github.com/jaredlll08) for their work on this project and providing the information required to make this project a reality.

## Required Mods

### 1.18.2 -> 1.21
- [Simply Swords](https://www.curseforge.com/minecraft/mc-mods/simply-swords)

### 1.20.1 -> 1.21
- [Fzzy_Config](https://www.curseforge.com/minecraft/mc-mods/fzzy-config)

### 1.18.2 -> 1.19.2
- [Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api)
- [Cloth Config](https://www.curseforge.com/minecraft/mc-mods/cloth-config)
